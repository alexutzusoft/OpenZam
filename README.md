# OpenZam

**Open-source audio fingerprinting and song identification engine.**

---

## Overview

OpenZam is an open-source Python application that identifies songs from short audio clips using Shazam-style constellation fingerprinting. Designed for developers, music enthusiasts, and privacy-conscious users, it delivers fast, local song matching without relying on external cloud APIs or third-party servers.

## Features

- **Constellation Fingerprinting** — Uses peak-pair spectral hashing and time-offset alignment for accurate short clip recognition.
- **Fast & Parallel Matching** — Employs an inverted hash index and parallel CPU execution for rapid database indexing and lookup.
- **Privacy-First & Local** — Processes all audio files entirely on your local machine without sending data to external services.
- **Universal Format Support** — Supports MP3, FLAC, OGG, WAV, M4A, AAC, WMA, and Opus audio formats out of the box.
